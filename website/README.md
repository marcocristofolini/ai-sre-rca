# Tracecroft AI website

Standalone bilingual responsive static presentation for the open-source Tracecroft AI project. Includes a screenshot gallery with images from Chromium demo runs, controlled Kind multicausal validation, and the embedded original Archify 3.1.0 diagram.

## Preview

Serve the website directory through an ordinary local static HTTP server. Review both languages, gallery, responsive layouts, screenshots, source links, and architecture frame.

## Hosting

Intended for tracecroft-ai.marcocristofolini.dev. Create the subdomain and verify its document root and AutoSSL certificate through your hosting panel before transferring files. Do not install it over the main portfolio root. The site is static and has no database or secret environment variables.

## Scope

The benchmarks demonstrate controlled local results, not production accuracy or a commercial SLA. Incident remediation remains separate and explicitly approval-gated.
