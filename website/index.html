The investigation lifecycle

From incident signal to a defensible answer.

Tracecroft separates evidence collection from causal authority. Neither a model response nor a specialist's suggestion can override deterministic verification.

◉No arbitrary shell execution in the investigation path. Remediation is isolated and requires explicit approval.
01
Authorize the scope

Choose an allowed cluster, workload and bounded time window.

02
Collect live evidence

Read Kubernetes, Prometheus, Loki, Tempo and selected dependency sources.

03
Test independent hypotheses

Check provenance, hash integrity, ownership and repeated causal signals.

04
Persist a bounded verdict

Store primary and additional supported roots with linked evidence and audit context.

05
Review before acting

Inspect findings in the workspace; remediation remains separately gated.

Scope by design

Tenant, cluster, workload and bounded time window are checked before live reads. Inventory is resolved by UID rather than matching names.

Evidence integrity

Correlate independent sources and preserve SHA-256 evidence references. Unverified claims do not become deterministic root causes.

Human approval

Investigation uses read-only adapters. Remediation is a separate, disabled-by-default workflow with explicit approval and audit controls.

FAQ

Questions before you integrate.

Is Tracecroft AI production-ready?

This is an open-source engineering release candidate. Controlled local tests have passed, but that is not equivalent to audited production readiness, broad accuracy measurement or a service-level guarantee.

Does it autonomously change my infrastructure?

No. Investigation adapters are read-only. Remediation is isolated, disabled by default and requires policy checks, review and approval.

What makes a second root cause valid?

It must have its own confirmed deterministic playbook hypothesis, integrity-verified evidence and independent causal verification. It is not inferred from a coincident alert or generated text.

Can I run it without an LLM?

Yes. Deterministic evaluation and Copilot fallbacks work without model execution. Optional model-assisted planning is experimental and separately gated.

How do I start locally?

Clone the public repository, review the .env example, then run Docker Compose. Demo mode is not a hardened production installation. Consult the operations and security documentation before attaching real clusters.
